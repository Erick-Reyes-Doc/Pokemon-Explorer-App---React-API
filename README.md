# 🧩 Pokémon Explorer App - React + API

Una app interactiva desarrollada con **React** que permite explorar y visualizar información de distintos Pokémon utilizando la [PokéAPI](https://pokeapi.co/) 🎮

---

## 📱 ¿Qué puedes hacer con esta app?

- 🔎 Buscar y explorar Pokémon por nombre o ID.
- 🖼️ Ver imagen, tipos, habilidades y estadísticas base.
- 📥 Cargar dinámicamente desde la API oficial de Pokémon.
- 🧭 Navegar entre pokémones de forma simple y rápida.
- ⚡ Experiencia responsive y amigable.


---

## 🛠️ Tecnologías utilizadas

- ⚛️ React + Vite
- 🌐 PokéAPI (https://pokeapi.co)
- 💅 CSS personalizado / Tailwind (opcional)
- 📦 Axios o `fetch` para consumir la API
